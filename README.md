# KUDRYAVKA // SAPIENTIA

Grand Harmony Directorate 사피엔티아 입단 신청서 — 쿠드랴프카 세베랴노비치 이바노프 캐릭터 소개 페이지.

## 현재 상태

- 신청서 원문 전체를 반영했다(문장 단위 대조 완료). 띄어쓰기만 조금 다듬었고, 맞춤법은 "배여있는 → 배어 있는" 한 곳을 고쳤다.
- 아직 "입력 대기"로 남은 칸: 프로필 그림. `assets/profile.png` 이름으로 넣으면 표지 사각 프레임에 바로 나온다(정사각형 권장, 다른 비율이면 가운데를 기준으로 잘림). 파일이 없으면 "입력 대기"가 보인다.
- 이면 세계 연출에 떠오르는 혼잣말(`assets/main.js`의 `MURMUR`)은 원문에 트라우마 설정이 없어 쿠드랴프카 본인의 대사 조각으로 만들었다. 설정이 생기면 그 줄만 바꾸면 된다.
- 표지 아래 설계도는 원문의 "공식적으로 그의 이름이 적힌 우주 비행 기록은 없다"에 맞춰 `Flight record — 공식 기록 없음`으로 표기했다.

## 특수능력 시뮬레이터 (별들의 사슬)

- 적(E1~E11)을 눌러 차례로 사슬을 잇는다. 첫 대상은 판정 없이 연결된다.
- 두 번째 대상부터 연결할 때마다 정신력 판정을 한다. 성공률은 시연용 임의값(두 번째 90%, 이후 한 명마다 10%p 감소)이며 화면에도 그렇게 적혀 있다. 바꾸려면 `main.js`의 `const p = Math.max(.1, .9 - .1 * (linked.length - 1));`를 고친다.
- 판정에 실패하면 직전까지 연결된 적에게만 사슬이 남고 더 잇지 못한다. 최대 7명.
- 2명 이상 연결되면 `다음 턴 공격 적중 → 연쇄`로 사슬을 부순다. 연결된 모두에게 `동일 피해`가 표시된다.

## 파일 구성

```
index.html          페이지 본체
assets/style.css    디자인 (페이지는 무채색, 색은 별에만)
assets/main.js      성운·별, 블랙홀, 별자리, 발현 능력 시뮬레이터, 사운드
assets/sapientia_symbol.png  사피엔티아 문장 (배경 투명, 600×600)
assets/og.png       공유 미리보기 그림 (1200×630)
assets/favicon.png  탭 아이콘 / apple-touch-icon.png  홈 화면 아이콘
assets/bgm.mp3      배경 음악 (직접 넣기, 아래 참고)
```

## 배경 음악 넣기

- 노래 파일을 `assets/bgm.mp3` 이름으로 넣으면 된다. 다른 이름이나 형식(.m4a, .ogg)을 쓰려면 `index.html`의 `<audio id="bgm" src="...">`만 고친다.
- 기본 볼륨은 35%이고, 켤 때 1.5초에 걸쳐 서서히 커진다. 바꾸려면 `assets/main.js`의 `const VOL = 0.35;`를 고친다.
- 효과음(섹션 도착 차임, 스푸트니크 신호음, 순간이동 소리)은 그대로 브라우저에서 합성하며, 배경 음악과 함께 SOUND 버튼 하나로 켜고 끈다.
- 파일이 없으면 예전의 잔잔한 합성 배경음이 대신 나온다.
- 노래는 반복 재생되며, 다른 탭으로 가면 멈췄다가 돌아오면 다시 재생된다.

## GitHub Pages에 올리기

1. 새 저장소(public)에 이 폴더 안의 파일을 구조 그대로 올린다 (`assets` 폴더째).
2. `Settings` → `Pages` → Source `Deploy from a branch`, Branch `main` / `/ (root)` 저장.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열린다.

다른 캐릭터 페이지와 한 저장소에 같이 올릴 때는 캐릭터마다 폴더를 나눈다(`저장소/폴더명/`).

## 선관 이름에 링크 걸기

`index.html`의 11번 선관 섹션(11.1 칸)에 예시가 주석으로 들어 있다. `<ul class="rel">` 안에 한 줄씩 넣으면 이름을 눌렀을 때 그 사람 페이지로 이동한다.

```html
<li><a class="rel__link" href="../폴더명/">선관 이름</a><span class="rel__note mono">관계 한 줄</span></li>
```

- 같은 저장소 안의 페이지는 `../폴더명/` 처럼 상대 경로로 쓴다.
- 다른 곳에 있는 페이지는 전체 주소(`https://...`)를 쓰고 `target="_blank" rel="noopener"`를 붙인다.
- 링크가 없는 선관은 `<span class="rel__name">이름</span>`으로 두면 같은 모양의 일반 글자로 보인다.

## 디자인 메모

- 색은 별에만 쓴다: 깊은 보라 #8A5CFF, 자홍 #D14FE0, 금빛 #F6CF7C. 발로란트 아스트라의 게임 내 연출을 참고해 고른 근사값이며 공식 색상 코드는 아니다. 예외로 블랙홀은 요청에 따라 금빛이다. 성운, 별자리 선, 레일, 글자, 패널은 모두 무채색이다.
- 섹션 순서: 표지(블랙홀 → 프로필 → 이름 → 원어 이름 → 인용문 → 기본 정보 → 오른쪽 설계도) → 01 신원 정보 → 02 외관 → 03 성격 → 04 L/H/S → 05 능력치 → 06 기술 → 07 특수능력 → 08 발현 능력 → 09 특징 → 10 소지품 → 11 선관 → 입단 각오 → 본문 링크.
- 표지: 블랙홀과 프로필 그림은 따로 놓인다(블랙홀 → 네모난 프로필 → 이름). 표지 아래 오른쪽에는 옛 탑승 기체 설계도가 있다. 모양과 수치(지름 58cm 구체, 2.4m·2.9m 안테나 4개, 20.005/40.002MHz 송신기)는 스푸트니크 1호에서 가져왔고, 제목은 원문에 맞춰 `Flight record — 공식 기록 없음`이다. 그리고, 탄생 별자리 성도는 01 신원 정보 끝으로 옮겼다. 블랙홀은 금빛, 가운데는 검은색이다. 원반의 가까운 쪽은 그림자 앞을, 먼 쪽은 뒤를 지나고, 먼 쪽의 빛이 휘어 그림자 위아래를 감싸는 고리로 보인다.
- 별자리 11개(큰곰, 카시오페이아, 거문고, 백조, 오리온, 독수리, 전갈, 남십자, 북쪽왕관, 쌍둥이, 북극성)가 각 섹션에 도착할 때 은빛 선으로 이어진다(별 자체만 색을 띤다). 모양은 실제 배열을 단순화했다. 넓은 화면에서만 보인다.
- 배경 별: 처음 한 번만 그려 두는 층(은하수를 이루는 미세 별 구름과 먼지 띠, 세 단계 밝기의 별 수천 개, 색 광륜 별, 산개 성단 2~4개)과 매 프레임 움직이는 층(반짝이는 별 170개, 회절 광채를 가진 밝은 별 26개)으로 나뉜다. 렌더링 배율은 1.5배로 제한해 고해상도 화면에서도 무겁지 않게 했다. 14~24초마다 스푸트니크형 구체가 안테나를 끌며 지나간다. 사운드를 켜 두면 지나가는 동안 1초에 세 번쯤 번갈아 울리는 신호음이 난다(실제 스푸트니크 신호 간격을 본뜸, 음 높이는 들을 수 있게 바꿈).
- 첫 진입 시 광과민성 발작 경고 + 배경 음악 안내(소리를 줄여 달라는 문구)가 먼저 뜬다. 3초 읽기 시간이 지나야 `소리 켜고 보기` / `소리 끄고 보기`가 눌린다(`main.js`의 `const LOCK = 3000;`). `웹사이트 보지 않기`를 누르면 구글 독스 본문 링크 버튼이 나온다(링크 입력 대기, `index.html`의 `gateDoc`에 주석으로 넣는 방법이 있다). 같은 탭에서 새로고침하면 경고는 다시 뜨지 않고, 이전에 소리를 켰다면 다시 켜 본다(브라우저가 막으면 꺼진 채로 시작).
- 경고를 통과하면 발사 카운트다운(T−3 → T−2 → T−1, 각 0.8초, 그다음 lift off)이 별하늘 위에 뜬다. 같은 탭에서는 한 번만 나오고, 건너뛰기 버튼이 있으며, 움직임 줄이기 설정에서는 생략된다.
- 모바일에서는 별 수와 성운 해상도를 줄여 가볍게 했다.
- 사운드는 경고 화면에서 고른 대로 시작하며, 오른쪽 위 SOUND 버튼으로 언제든 켜고 끈다.

## 발현 능력 시뮬레이터 규칙

- 이동 후 5초 안에 `이전 지점으로 복귀` 버튼을 누르거나 출발 지점을 다시 누르면, 횟수를 차감하지 않고 되돌아간다(원문 ※ 규칙). 5초가 지나면 버튼이 꺼진다.

- 이동은 거의 즉발이다: 누르는 순간 도착하고, 접힘 선과 섬광은 0.16초 안에 끝난다. 연달아 눌러도 바로 다음 이동이 된다.
- 별 지도 한 변은 140m. 현재 위치에서 100m가 넘는 지점은 접을 수 없다(횟수 소모 없음).
- 밝은 원 안(익숙한 장소)은 정확히 도착, 바깥(처음 보는 장소)은 1~4.5m 빗나간다. 많이 쓸수록 오차가 커진다.
- 1~10회: 페이지가 점점 흑백으로 바래고 흐려지며, 4회부터 흔들린다. 시뮬레이터 자체는 흔들리지 않는다.
- 11회 이상: 상태가 CRITICAL로 바뀌고, 화면이 반전된 이면 세계로 4초간 넘어가며 혼잣말이 떠오른다.
- "하루 경과 · 리셋"으로 0회로 돌린다.

## 공유 미리보기 그림

- `assets/og.png`(1200×630)가 메신저·SNS에 링크를 붙였을 때 뜨는 그림이다.
- 지금은 `index.html`의 `og:image`가 `assets/og.png`처럼 짧은 경로로 되어 있다. 일부 서비스는 짧은 경로를 읽지 못하므로, 사이트 주소가 정해지면 `https://아이디.github.io/저장소/assets/og.png`처럼 전체 주소로 바꾸는 것이 확실하다.
- 미리보기는 서비스가 저장해 두는 경우가 많아서, 바꾼 뒤에도 한동안 예전 그림이 보일 수 있다.

## 선관 링크 바꾸기

`index.html`에서 `선관 링크: 이 부분을 수정해주세요` 주석을 찾는다. 바로 아래 줄의 `href="#"`에서 `#`만 상대 사이트 주소로 바꾸면 된다.

```html
href="#"   →   href="https://계정이름.github.io/저장소이름/"
```

- 주소를 넣으면 이름 옆에 ↗ 표시가 생기고, 누르면 새 탭으로 열린다.
- `#` 그대로 두면 눌러도 아무 일도 일어나지 않는다.
